## เกี่ยวกับหลักสูตร

หลักสูตรนี้ออกแบบมาเพื่อพาคุณจากศูนย์สู่การเป็น Java/Spring Boot Developer ระดับมืออาชีพ
ครอบคลุมตั้งแต่พื้นฐาน Java จนถึง Enterprise Application Architecture

## สิ่งที่ต้องการก่อนเรียน
- คอมพิวเตอร์ที่ใช้งานได้ (Windows/Mac/Linux)
- ความรู้พื้นฐานด้านคอมพิวเตอร์
- ความตั้งใจและความมุ่งมั่น

## เครื่องมือที่ใช้
- JDK 17+ (LTS)
- IntelliJ IDEA (แนะนำ) หรือ VS Code
- Maven หรือ Gradle
- Docker Desktop
- Git
